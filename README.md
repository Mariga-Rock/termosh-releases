## Что такое Termosh

Android-клиент для SSH и mosh. Работает локально: соединения идут напрямую
с телефона на сервер, никаких промежуточных серверов и аккаунтов.

Пароли, ключи и настройки хранятся в Android Keystore и зашифрованной
SQLCipher базе.
